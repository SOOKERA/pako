<h1 align="center">Pako releases</h1>

<p align="center">
  The download files for <a href="https://pako.sookera.com"><b>Pako</b></a>, a free download manager for Windows:<br>
  share big files with a link, send them straight to another PC, and download fast.
</p>

<p align="center">
  <a href="https://github.com/sookera/pako-releases/releases/latest"><b>Latest release</b></a> ·
  <a href="https://pako.sookera.com/checksums">Checksums</a> ·
  <a href="https://pako.sookera.com/help">Help</a>
</p>

| File | What it is |
|---|---|
| `Pako-Setup.exe` | Pako Setup: installs for you (no admin rights), with a Start menu entry and Uninstall in Windows |
| `Pako.exe` | Pako Portable: one file that runs from any folder |
| `latest.json` | What Pako reads to update itself (signed by us) |
| `help.zip` | The help guides of that version |
| `pako-firefox-1.2.x.xpi`, `pako-firefox.xpi` | Pako's browser extension for Firefox, signed by Mozilla (the same file under its version's name and a fixed one; Pako adds it from its Settings) |
| `firefox-updates.json` | Where Firefox looks for the extension's updates |
| `LICENSE`, `NOTICE.md` | The licence (GNU GPL version 3) and Sookera's additional terms, which go with every copy |

Both programs are the same and update themselves. Windows 10 and 11, 64-bit. The first time, Windows may say it
protected your PC: choose **More info**, then **Run anyway**.

Free software (GPL-3.0); the source code of each release is in [sookera/pako](https://github.com/sookera/pako).
Use it responsibly: see the [terms of use](https://sookera.com/terms).
